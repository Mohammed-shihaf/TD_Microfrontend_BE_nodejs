# TD_Microfrontend_BE_nodejs

Standalone Node.js (Express) backend for the **Micro-Frontend Platform**
project type — a real multi-module API (widgets CRUD-lite, an
embeddable-remotes registry, health), not a single bare route.

Not connected to any frontend by default. The paired standalone
frontends live in `TD_Microfrontend_FE_reactjs` and
`TD_Microfrontend_FE_angularjs`. The fully connected version of this
project type (all three modules wired together) lives in
`TD_Microfrontend_BE_nodejs_FE_reactjs_FE_angularjs`.

See ARCHITECTURE.txt for build commands and module layout.

Branches: one per Node.js version (18, 20, 22, 24).
